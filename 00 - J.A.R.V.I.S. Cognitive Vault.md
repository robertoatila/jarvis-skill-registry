## Consultas Dinâmicas do Dataview (Obsidian)

Se o plugin **Dataview** estiver ativo no seu Obsidian, as tabelas abaixo são renderizadas em tempo real a partir dos arquivos Markdown locais:

### 1. Skills Críticas Sinalizadas para Auditoria (`FLAGGED_FOR_REVIEW`)

```dataview
TABLE description, capabilities, version
FROM "skills"
WHERE security_status = "FLAGGED_FOR_REVIEW"
SORT file.name ASC
```

### 2. Top Skills de Engenharia de IA e RAG

```dataview
TABLE description, capabilities
FROM "skills"
WHERE contains(capabilities, "rag") OR contains(capabilities, "llm") OR contains(capabilities, "agent")
SORT file.name ASC
```

### 3. Laudos de Homologação Recentes

```dataview
TABLE file.mtime AS "Data de Modificação", file.size AS "Bytes"
FROM "reports"
SORT file.mtime DESC
LIMIT 10
```

## Comandos Nativos de Operação (Terminal PowerShell)

Você pode operar este cofre e o motor JARVIS diretamente pelo terminal:

- **Iniciar o Dashboard HUD no Navegador:**

```powershell
python jarvis.py
# Inicia o servidor na porta 8899 e abre a interface interativa com o Arc Reactor
```

- **Executar o Auto-Diagnóstico:**

```powershell
python jarvis.py --doctor
# Valida pré-requisitos locais em menos de 1 segundo sem chamadas de rede
```

- **Ingerir e Auditar um Novo Repositório do GitHub:**

```powershell
python jarvis.py --test
# Executa os testes rápidos e verificação de pré-voo
```

- **Sincronizar o Cofre do Obsidian com o Arsenal:**

```powershell
powershell -ExecutionPolicy Bypass -File tooling/Sync-ObsidianVault.ps1
# Atualiza os índices semânticos e links bidirecionais [[links]] para todas as skills
```
