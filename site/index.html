Quickstart

Start in 3 commands.

Zero required pip dependencies to launch. J.A.R.V.I.S. is built on Python 3.10+ standard library.

Clone, verify, and launch Mark-LIV Cockpit HUD PORT 8899 
# 1. Clone repository
$ git clone https://github.com/robertoatila/jarvis-skill-registry.git
$ cd jarvis-skill-registry

# 2. Run offline doctor check (< 1 second)
$ python jarvis.py --doctor

# 3. Launch Mark-LIV Cockpit HUD on http://127.0.0.1:8899
$ python jarvis.py

To run as an MCP Server for Antigravity, Cursor, or Claude Code: python tooling/jarvis_mcp_server.py
