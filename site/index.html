Why it exists

Most agents optimize demos. This one optimizes proof.

Conventional frameworks concatenate context until the model silently truncates, run tools without authority rings, and accept “Done!” as success. J.A.R.V.I.S. enforces systems invariants on every turn.

01

Bounded context

compile_context() admits only what fits a UTF-8 byte budget and emits loaded/omitted receipts — no silent truncation.

02

Governed tools

Canonical skills with SHA-256 digests, Merkle anchoring, and authority rings R0–R3. Fail-closed quarantine blocks unsafe artifacts.

03

Verified completion

EvidenceVerifier checks exit codes, stdout, and hashes before any task may transition to PASS.

Completion semantics

No PASS without evidence

Every governed turn walks intake → authority → skill lookup → bounded context → sandboxed run → verifier → governor verdict → immutable timeline receipt. The LLM does not get the last word.

  • Authority rings gate read vs mutation capabilities.
  • Context governor drops stale inputs under budget pressure.
  • Merkle + SHA-256 anchor skill integrity and quarantine blocks.

Fail-closed

Sovereign Security Protocol (SSP-v13.4)

No tool execution or network dispatch without prior verification. If checks fail, the path stays closed.

1 OBSERVE→ 2 PLAN→ 3 RESOLVE→ 4 EXECUTE→ 5 VERIFY→ 6 MEASURE→ 7 LEARN

Quarantine link

Cryptographic tombstones for malicious or unstable artifacts blocked at the root before execution.

Pre-publish hygiene

Automated scans (including entropy checks) to reduce credential leakage before publish paths.

Context budget law
