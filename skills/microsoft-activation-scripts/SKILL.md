# microsoft-activation-scripts

## Visão Operacional
Habilidade canônica implementada autonomamente pelo J.A.R.V.I.S. a partir de `massgravel/Microsoft-Activation-Scripts` (193429 estrelas no GitHub).

## Diretrizes de Uso
- **Soberania Local**: Operação determinística em conformidade com o Protocolo SSP-v13.
- **Governança de Tokens**: Descrição concisa no frontmatter YAML garantindo integridade de contexto.
- **Esquadrão Responsável**: `Hyperion-FullStack`.
