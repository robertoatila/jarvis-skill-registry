## Task 3 — Adaptive Governor Decision Contract

**Files:**
- Create: `tests/test_agentic_v020_adaptive_governor.py`
- Modify: `tooling/agentic/cognitive_governor.py`

Add:

```python
class GovernorAction(str, Enum):
    CONTINUE = "CONTINUE"
    EXPAND_CONTEXT = "EXPAND_CONTEXT"
    ESCALATE_CAPABILITY = "ESCALATE_CAPABILITY"
    REPLAN = "REPLAN"
    STOP = "STOP"
    REQUIRE_HUMAN = "REQUIRE_HUMAN"

@dataclass(frozen=True)
class GovernorObservation:
    authority_valid: bool
    risk_level: RiskLevel
    confidence: Optional[float]
    evidence_sufficient: bool
    context_exhausted: bool
    eligible_alternatives: int
    attempts: int
    repeats: int
    remaining_tokens: Optional[int]
    remaining_cost_usd: Optional[float]
    recovery_state: RecoveryState
```

Define deterministic decision priority:

1. invalid authority / unsafe recovery / explicit human gate → REQUIRE_HUMAN or STOP;
2. exhausted hard budget → STOP;
3. insufficient evidence with useful context available → EXPAND_CONTEXT;
4. insufficient evidence + stronger eligible capability → ESCALATE_CAPABILITY;
5. invalidated plan assumptions → REPLAN;
6. otherwise CONTINUE.

No hidden weighted scalar mixes dollars/tokens/latency/risk. Any future aggregate must declare normalization/version.

Test every action, boundary equality, UNKNOWN resource values, repeat-loop protection and per-mission isolation.

Commit: `feat: make cognitive governor adapt from bounded observations`
