# J.A.R.V.I.S. v0.2.0 Trusted Runtime + Receipts Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Close the P0 trust gaps in durable schemas, resource accounting, authorization, execution receipts, verification receipts and restart/recovery semantics.

**Architecture:** Extend the existing `models.py`, `policy.py`, `admission.py`, `runtime.py`, `verification.py`, `resilience.py`, `state_store.py` and `budgets.py`. Add only narrowly scoped migration/authorization/receipt modules where no equivalent exists. Do not create parallel runtime subsystems.

**Tech Stack:** Python 3.12 stdlib + unittest.

**Spec:** `docs/superpowers/specs/2026-09-15-jarvis-v0.2.0-optimization-design.md`

## Global Constraints

- TDD is mandatory: add tests, run them and observe RED before implementation.
- `v0.1.0` release machinery is untouched.
- Unknown measurement is never coerced into zero.
- No universal token→USD conversion.
- Approval is not durable authorization unless action/scope/budget context matches and the grant is valid.
- Recovery cannot replay an ambiguous mutable effect.

## Task 3 — Durable Authorization Grants

**Files:**
- Create: `tests/test_agentic_v020_authorization_grants.py`
- Create: `tooling/agentic/authorization.py`
- Modify: `tooling/agentic/policy.py`
- Modify: `tooling/agentic/admission.py`
- Modify: `tooling/agentic/config.py`

Add a canonical grant model bound to a canonical digest:

```python
@dataclass
class AuthorizationGrant:
    grant_id: str
    task_id: str
    subject: str
    action: str
    scope_digest: str
    budget_digest: str
    issued_utc: str
    expires_utc: str
    revoked_utc: Optional[str] = None
```

Canonicalize action/scope/budget as sorted JSON before SHA-256 hashing. Grant verification must reject:

- expired grant;
- revoked grant;
- task/subject mismatch;
- action mismatch;
- path alias/scope mismatch;
- budget expansion after approval;
- malformed digest;
- autonomous self-approval.

Persist grants atomically under `state/authorizations/`; add `authorizations_dir` to runtime config. `PolicyEngine` remains the authority evaluator; the new module stores/verifies the durable grant produced from an approved request.

Focused command:

```bash
python -m unittest tests.test_agentic_v020_authorization_grants tests.test_agentic_foundation tests.test_agentic_runtime_hardening -v
```
